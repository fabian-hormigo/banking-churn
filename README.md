## 🚀 What is this project?

This project builds a **machine learning system to predict customer churn in a banking environment**.

Customer churn happens when a client stops using a bank’s services.  
The goal is to **detect it early and help banks retain customers before they leave**.

---

## 🎯 Objective

Build an **end-to-end ML pipeline** that predicts:

- `0` → Customer stays  
- `1` → Customer churns  

---

## 🧠 Problem Type

- Binary Classification  
- Supervised Learning  
- Real-world Banking Use Case  

---

## 📊 Data Features

Typical inputs include:

- 👤 Age  
- 💰 Income  
- 🏦 Account balance  
- 💳 Debt level  
- 📦 Number of products  
- 📈 Transaction activity  
- ⏳ Customer tenure  
- 📱 Digital engagement
